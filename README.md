# Házias ízek - Reszponzív weboldal

**Nyelv:** HU Magyar | [GB English](README_EN.md)

![Kezdőlap képernyőképe](/public/assets/images/hazias_izek.png)

Ez a projekt a **Fullstack Webfejlesztő képzés** első moduljában (HTML + CSS + alap JavaScript/jQuery) készült **házi feladatként**, amely egy **fiktív gasztronómiai weboldal** megvalósítását mutatja be.

## Leírás

A Házias ízek egy egyszerű, reszponzív weboldal, amely:
- bemutatja a webes elrendezés (grid, flex) használatát,
- tartalmaz **lenyíló (többszintes) navigációs menüt**,
- tartalmaz **reszponzív megjelenést több törésponttal (media query)**,
- jQuery segítségével működtetett **mobil navigációs menüt**,
- modern, esztétikus megjelenést biztosít a **Google Fonts** használatával.

## Fő funkciók

- Reszponzív webdesign (mobil, tablet, desktop)
- Többszintű navigációs menü
- Hamburger menü mobilnézetben
- Interaktív menüanimációk jQuery segítségével
- Esztétikus grid-elrendezés képes kártyákkal
- Visszajelzések szekció grid elrendezésben
